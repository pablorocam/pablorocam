## How I work

- **Discovery before code.** I sit with the people who run the operation, map the real workflow and agree on what "done" means before building.
- **Spec-first, evals before deploy.** Behavior changes start as a written spec; models and prompts are measured against held-out test sets, not vibes.
- **Human in the loop by design.** When the system is unsure it asks a person; it never guesses silently.
- **Build with agents, own the result.** Claude Code writes most of the code; I decide the architecture, review every change and am accountable for what ships.
- **Boring and explicit beats clever.** Fewer screens, fewer menus, sensible defaults. Software is measured by how much it gets used.
- **Local when it should be local.** Comfortable running open models on my own GPUs when cost, privacy or latency call for it, and switching to hosted APIs when they don't.
